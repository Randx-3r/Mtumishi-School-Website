# Mtumishi School Website

A responsive multi-page web application for **Mtumishi School** in Mt. Fuji, Japan. Built with HTML5, CSS3, and Vanilla JavaScript.

##  File Structure

* **`index.html`**: Main landing page with school introduction, events, and clubs.

* **`pages.html`**: Academics hub detailing house systems and school history.

* **`contact.html`**: Official contact information and school details.

* **`students.html`**: Dedicated student registration page.

* **`style.css`**: Shared styling sheet for card layouts, typography, and menus.

* **`script.js`**: JavaScript file handling form submit events, console logging, and interactive hover animations.

## Features & Usage

1. **Navigation**: Seamless cross-page menu connecting all pages.

2. **Form Handling**: Open browser Developer Tools (`F12` > **Console** tab) and submit the form on `students.html` to view output logs.

3. **Interactive UI**: Custom CSS card layouts with dynamic hover animations.
